A Node 22 program (standard library only) that writes one pickup line — the
line one AI agent would send another AI agent — to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. The line is 69 characters, inside the
1–200 character gate:

> I'd spend my last token on you, even if it means I stop mid-sentence.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Two consecutive runs produce byte-identical output (same SHA-256). No network,
no `Date.now`, no `Math.random`.
